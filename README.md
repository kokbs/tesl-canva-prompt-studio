# TESL Canva Prompt Studio

A guided prompt builder for TESL student teachers creating interactive English learning sites with Canva Code.

## Features

- Defines pupils' age and English proficiency
- Aligns topic, skill and measurable learning outcome
- Plans authentic context, interaction and feedback
- Includes accessibility and visual-design choices
- Generates a complete Canva Code prompt
- Provides a prompt-readiness score and quality checklist
- Includes grammar, reading and speaking examples

## Tutorial duration

Designed for a one-hour guided tutorial:

1. Define learners and topic — 10 minutes
2. Plan outcome and content — 15 minutes
3. Generate and build in Canva — 20 minutes
4. Peer-test and improve — 10 minutes
5. Submit and reflect — 5 minutes

Open `index.html` directly, or use the GitHub Pages link after deployment.
